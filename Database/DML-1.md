# DML-1

### 데이터 조작어 (DML, Data Manipulation Language)
- 데이터베이스의 데이터를 **조회, 삽입, 수정, 삭제**하는 데 사용
- 데이터베이스 사용자가 직접 사용하거나 응용 프로그램을 통해 사용

---
## SELECT 문
**데이터를 조회할 때 사용하는 가장 기본적인 명령어**
> 💡 SQL 분류 방식에 따라 `SELECT`를 DML에 포함하거나 DQL로 별도 분류하기도 한다.

### **작성 순서**
1. SELECT
2. FROM
3. WHERE
4. GROUP BY
5. HAVING
6. ORDER BY

### **해석 순서**
> 컴퓨터가 해석하는 순서로 해석하면 더 쉽게 쿼리를 해석할 수 있다.
1. FROM
    
    어떤 테이블에서 데이터를 가져올지 결정
    - 디스크에 있는 데이터를 메모리에 로드하여 기본 데이터셋 구성

2. WHERE

    조건에 맞는 행을 필터링
    - 불필요한 데이터 연산을 줄임 (GROUP BY, HAVING 등에서 불필요하게 연산할 것을 미리 줄여줌)

3. GROUP BY

    데이터를 그룹으로 묶음
    - 메모리상에서 데이터를 그룹으로 묶어, 집계 처리 위한 구조로 변환

4. HAVING

    그룹에 대한 조건을 필터링
    - 기준에 맞는 그룹만 남김

5. SELECT

    조회하고자 하는 열(컬럼)을 조회
    - 필요한 컬럼과 계산 값만 메모리에 남기고 출력 준비

6. ORDER BY

    정렬 기준 설정
    - 정렬은 메모리와 CPU 연산량이 크기 때문에 가장 마지막에 수행

## WHERE 절
**특정 조건에 부합하는 튜플(행) 데이터 조회할 때 사용**

**`학생` 테이블**
|학번|이름|나이|
|---|---|---|
|101|홍길동|20|
|102|이순신|21|
|103|임꺽정|20|
|104|장보고|21|
|105|강감찬|22|
|106|이성계|23|

### 기본 비교 연산자
- **같다(=)**
    ```SQL
    SELECT 이름 FROM 학생
    WHERE 나이 = 21
    -- → 이순신, 장보고
    ```

- **다르다(!=, <>, ^=)**
    ```SQL
    SELECT 이름 FROM 학생
    WHERE 나이 != 21
    -- → 홍길동, 임꺽정, 강감찬, 이성계
    ```

- **크다(>)**
    ```SQL
    SELECT 이름 FROM 학생
    WHERE 나이 > 22
    -- → 이성계
    ```

- **작다(<)**
    ```SQL
    SELECT 이름 FROM 학생
    WHERE 나이 < 22
    -- → 홍길동, 이순신, 임꺽정, 장보고
    ```

- **크거나 같다(>=)**
    ```SQL
    SELECT 이름 FROM 학생
    WHERE 나이 >= 22
    -- → 강감찬, 이성계
    ```

- **작거나 같다(<=)**
    ```SQL
    SELECT 이름 FROM 학생
    WHERE 나이 <= 22
    -- → 홍길동, 이순신, 임꺽정, 장보고, 강감찬
    ```

- **NULL에서는 연산자 사용 X**
    ```SQL
    WHERE 나이 IS NULL
    WHERE 나이 IS NOT NULL
    -- = NULL과 같이 비교하면 안됨
    ```

### 조건 표현 연산자
- **두 조건 모두 만족(AND)**
    ```SQL
    SELECT 이름 FROM 학생
    WHERE 나이 >= 21 AND 나이 <= 22
    -- → 이순신, 장보고, 강감찬
    ```

- **두 조건 중 하나 이상 만족(OR)**
    ```SQL
    SELECT 이름 FROM 학생
    WHERE 나이 = 20 OR 나이 = 23
    -- → 홍길동, 임꺽정, 이성계
    ```

- **여러 값 중 하나(IN)**
    ```SQL
    SELECT 이름 FROM 학생
    WHERE 나이 IN (20, 21)
    -- → 홍길동, 이순신, 임꺽정, 장보고
    ```

- **범위 조건(BETWEEN A AND B)**
    ```SQL
    SELECT 이름 FROM 학생
    WHERE 나이 BETWEEN 21 AND 22
    -- → 이순신, 장보고, 강감찬
    ```

- **조건에 해당하지 않음(NOT)**
    ```SQL
    SELECT 이름 FROM 학생
    WHERE 나이 NOT IN (20, 21)
    -- → 강감찬, 이성계
    ```

### 문자열 패턴 검색
- **문자열 패턴 검색(LIKE)**
    ```SQL
    SELECT 이름 FROM 학생
    WHERE 이름 LIKE '이%'
    -- → 이순신, 이성계

    /*
    와일드카드
    % → 0개 이상의 문자
    _ → 1개의 문자만
    */
    ```

## GROUP BY 절
**특정 컬럼을 기준으로 행들을 그룹화하여 그룹별 데이터를 조회**

**`직원` 테이블**
|사번|부서|급여|
|---|---|---|
|101|인사|800|
|102|개발|1200|
|103|기획|1200|
|104|개발|1300|
|105|개발|1100|
|106|인사|900|
|107|기획|1400|
|108|인사|1200|
|109|인사|1100|
|110|기획|700|

```SQL
SELECT 부서, AVG(급여) AS 평균급여 FROM 직원 GROUP BY 부서
-- AVG = 평균
```

|부서|평균급여|
|---|--------|
|인사|1000|
|개발|1200|
|기획|1100|

### 집계 함수 유형
|집계 함수|설명|
|---------|---|
|**COUNT**|행 수 계산|
|**SUM**|합계 계산|
|**AVG**|평균값 계산|
|**MAX**|최댓값 계산|
|**MIN**|최솟값 계산|

## HAVING 절
**그룹화(GROUP BY)된 결과에 대한 조건**
> `WHERE`는 **그룹화하기 전의 행**을 필터링하고, `HAVING`은 **그룹화된 결과**를 필터링한다.

**`직원` 테이블**
|사번|부서|급여|
|---|---|---|
|101|인사|800|
|102|개발|1200|
|103|기획|1200|
|104|개발|1300|
|105|개발|1100|
|106|인사|900|
|107|기획|1400|
|108|인사|1200|
|109|인사|1100|
|110|기획|700|

```SQL
SELECT 부서, AVG(급여) AS 평균급여 FROM 직원 GROUP BY 부서 HAVING AVG(급여) > 1000
```

|부서|평균급여|
|---|--------|
|개발|1200|
|기획|1100|

## ORDER BY 절
**결과를 정렬할 때 사용**

|정렬 키워드|설명|
|-----------|---|
|**ASC**|오름차순 (기본값)|
|**DESC**|내림차순|

### 오름차순 (ASC)
**`직원` 테이블**
|사번|급여|
|----|----|
|101|1300|
|102|1100|
|103|1200|
|104|1500|
|105|1100|

```SQL
SELECT 사번, 급여 FROM 직원 ORDER BY 급여
```

|사번|급여|
|----|----|
|102|1100|
|105|1100|
|103|1200|
|101|1300|
|104|1500|

### 내림차순 (DESC)
**`직원` 테이블**
|사번|급여|
|----|----|
|101|1300|
|102|1100|
|103|1200|
|104|1500|
|105|1100|

```SQL
SELECT 사번, 급여 AS 연봉 FROM 직원 ORDER BY 연봉 DESC
-- 별칭(Alias)으로도 정렬 가능
```

|사번|연봉|
|----|----|
|104|1500|
|101|1300|
|103|1200|
|105|1100|
|102|1100|

### 다중 정렬
**`직원` 테이블**
|사번|급여|보너스|
|----|----|-----|
|101|1300|100|
|102|1100|20|
|103|1200|0|
|104|1500|30|
|105|1100|50|

```SQL
SELECT 사번, 급여 AS 연봉, 보너스 FROM 직원 ORDER BY 급여 DESC, 보너스 ASC
-- 급여(연봉) 내림차순, 보너스 오름차순
```

|사번|연봉|보너스|
|----|----|-----|
|104|1500|30|
|101|1300|100|
|103|1200|0|
|102|1100|20|
|105|1100|50|

> `연봉`을 먼저 내림차순한 뒤 동일 값일 시 `보너스`를 오름차순하여 정렬한다.
